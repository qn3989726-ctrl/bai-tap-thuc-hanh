Biến CSS (CSS Variables)

Toàn bộ màu sắc được khai báo trong :root và ghi đè bằng class .dark-mode.

Chuyển đổi bằng JavaScript

Nút gạt thêm/bỏ class .dark-mode trên <body> — mọi thành phần tự đổi màu.
